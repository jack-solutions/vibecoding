# 🎬 VideoHub — YouTube-Style Video Platform

A **modern, fully client-side YouTube-style video-sharing application** built with **React, TypeScript, and Tailwind CSS**.  
All videos, channels, comments, and subscriptions are stored locally via **localStorage**, meaning **no backend is required**.

## ✨ Features

- 🏠 **Home Page** — Video grid, search, and filtering (All / Trending / Latest / Popular)
- 🎥 **Watch Page** — Custom video player, likes, comments & related videos
- ⬆ **Upload Page** — Upload videos with thumbnails, metadata & channel selection
- 📺 **Channel Page** — Channel banner, subscribers & video listings
- ⭐ **Subscriptions System** — Subscribe/unsubscribe channels
- 💾 **Local Persistence** — All data stored in `localStorage`
